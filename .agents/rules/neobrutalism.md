# Neobrutalism UI Rules

- NEVER use soft blurred shadows (shadow-sm, shadow-md, shadow-lg, shadow-xl) or gradients.
- Every card, button, badge, and input MUST use `border-2 border-black` (or `border-4 border-black`).
- All elevation MUST use hard offset shadows: `shadow-[4px_4px_0px_0px_#000000]`.
- Interactive buttons MUST translate down-right on hover/active to simulate a physical button press.
- Use Space Grotesk for headings and JetBrains Mono for technical stack badges and metrics.
